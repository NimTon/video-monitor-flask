# 模块名称  
报警分发模块 alert_dispatcher.py

## 模块定位  
该模块负责在视频监控系统中，将检测到的异常事件通过多种渠道（如钉钉、短信、邮箱、微信等）进行报警推送，并结合 AI 模型判断结果，渲染报警模板内容，实现完整的智能预警通知机制，是报警子系统的核心模块之一。

## 技术栈与依赖  
- Python 3.10+
- OpenCV 4.x（图像处理）
- requests（HTTP 请求）
- smtplib / email（邮件发送）
- base64 / hashlib / hmac（加解密和签名）
- qwen_ai 客户端（调用 AI 图像识别接口）
- storage.py（读取报警模板、联系人等配置信息）

## 输入与输出  
- 输入：
  - 视频截图帧（numpy 数组列表）
  - 围栏检测结果（fence_result：包含变化比率和围栏ID）
  - 视频流 ID（stream_id）

- 输出：
  - AI 返回的判断结果（如是否异常、描述语句等）
  - 渲染后的报警消息文本
  - 报警信息通过以下方式分发：
    - 钉钉（机器人 webhook + 签名）
    - 短信（短信宝 API）
    - 邮件（SMTP）
    - 微信（待实现）

## 核心功能与逻辑说明  

### 1. AI 多帧判别  
通过 `call_qwen_via_client()` 将一组图像帧（Base64编码）发送至多模态 AI 模型，由其判断是否为真正异常。  
> ✅ 若 AI 返回结果为“正常”，则直接忽略当前报警事件。

### 2. 模板渲染  
从 `alert_storage` 中读取预设的报警模板，插入如流名称、围栏ID、变化比率、AI 报告文本等变量，生成最终的报警消息内容。

### 3. 报警渠道支持  
系统支持以下报警渠道，每个渠道对应一套发送函数：
- **钉钉**：支持签名、access_token 分离配置，安全性高
- **短信**：基于短信宝 API，适用于紧急通知
- **邮箱**：通过 SMTP 登录 QQ 邮箱发送 HTML 邮件
- **微信**：预留接口，后期可接入企业微信应用消息等

### 4. 多接收人支持  
通过 `recipients.json` 中配置的接收人，支持每位接收人配置多个报警渠道，例如同时收到钉钉和邮件通知。

### 时序逻辑图（简化）  
```

事件触发
↓
图像帧缓存 + 围栏检测结果
↓
\[AI 模型判断是否真正异常]
↓ 否
忽略报警
↓ 是
\[模板渲染] ← 读取 stream/config/recipients
↓
多渠道推送（钉钉 / 短信 / 邮件 / 微信）

````

## 配置说明  
- `alert_templates.json`：报警模板配置，支持 `{stream_name}`、`{timestamp}`、`{ai_report}` 等占位符替换
- `recipients.json`：接收人配置，每个接收人支持多种报警方式（字段如 `"dingding"`, `"sms"`, `"email"` 等）
- 报警图片默认保存在 `alerts/{stream_id}/{时间戳_变化比率}/prev.jpg` 和 `curr.jpg`

## 与其他模块的交互  
- 从 `video_stream.py` 中被调用（检测到异常后触发）
- 调用 `qwen_ai.py` 中 AI 判断接口获取图像识别结果
- 从 `storage.py` 中获取报警模板与接收人配置
- 调用系统网络模块发送邮件 / HTTP 请求发送钉钉 / 短信接口

## 调试建议  
1. 独立测试邮件报警：
```python
send_email_alert("测试内容", "xxx@example.com", "1.jpg", "2.jpg")
````

2. 本地调试短信报警（需先注册短信宝账号）：

```python
send_sms_alert("测试短信", "130xxxxxx")
```

3. 钉钉测试需要配置 webhook 和 secret：

```python
send_dingding_alert("测试消息", "access_token,secret")
```
