# 模块名称
电子围栏变化检测模块 `fence_detector.py`

## 模块定位
本模块是视频监控系统中用于检测电子围栏区域内变化的核心图像处理组件。它负责识别监控画面中指定区域（电子围栏）内的人员或物体移动情况，作为是否触发报警的关键判断依据。

## 技术栈与依赖
- Python 3.10+
- OpenCV 4.x（图像处理）
- NumPy（坐标和矩阵计算）
- 支持与其他模块集成：通过函数调用由 `video_stream.py` 等模块使用

## 输入与输出

### 输入：
- `frame`: OpenCV 获取的单帧图像（BGR 格式）
- `points`: 多边形顶点坐标列表，定义电子围栏区域
- `change_threshold`: 判定为“异常变化”的变化比例阈值，默认0.1

### 输出：
- `changed`: 布尔值，表示当前帧中电子围栏区域是否检测到显著变化
- `changed_area`: 整数值，表示变化区域的像素数

## 核心功能与逻辑说明

该模块包含以下关键功能：

### 1. 设置电子围栏区域 `set_fence(points)`
- 接收至少3个点，组成围栏的多边形区域；
- 使用 `cv2.contourArea()` 计算该区域的像素面积；
- 报错保护：少于3个点将抛出异常。

### 2. 检测变化 `detect_change(frame, change_threshold, debug)`
- 使用背景建模法（MOG2）对当前帧进行背景减除；
- 提取围栏内 ROI 区域；
- 应用掩码与形态学操作（腐蚀+膨胀）去噪；
- 计算变化像素数，并与围栏面积比较，判断是否超出阈值；
- 可选：显示调试窗口（debug=True）下图形化展示检测情况。

### 伪代码流程：
原始帧 → 提取围栏ROI → 背景建模 → 前景掩码 → 去噪 → 计算变化区域
→ 变化比例是否 > 阈值？→ True/False

### 示例调试界面：
调试模式下将显示：
- 绿色多边形围栏边界；
- 红色高亮的变化区域；
- 实时变化比例文字。

## 配置说明

| 配置项 | 说明 | 默认值 | 建议值 |
|--------|------|--------|--------|
| `change_threshold` | 判断是否为异常的变化比例阈值 | 0.1 | 0.05 ~ 0.2 |
| `history`（内部MOG2参数） | 背景建模帧历史长度 | 500 | 保持默认 |
| `varThreshold`（MOG2灵敏度） | 用于前景检测的阈值 | 50 | 可调 |

## 与其他模块的交互

- **由谁调用：**
  - `video_stream.py`：创建 `FenceChangeDetector` 实例，调用其 `set_fence` 和 `detect_change`；
- **提供给谁数据：**
  - 检测结果（布尔 + 像素数）作为判断是否进一步调用 AI 模块 `qwen_ai.py` 的条件；
  - AI 结果将用于填充报警模板，并由 `alert_dispatcher.py` 推送报警信息。

## 调试建议

你可以独立运行测试脚本来调试围栏检测效果：

```python
import cv2
from fence_detector import FenceChangeDetector

cap = cv2.VideoCapture(0)
detector = FenceChangeDetector()
detector.set_fence([(100,100), (300,100), (300,300), (100,300)])

while True:
    ret, frame = cap.read()
    if not ret:
        break
    detector.detect_change(frame, debug=True)
```
