## 模块名称
存储管理模块 storage.py

## 模块定位
该模块负责系统中视频流、电子围栏、告警模板及联系人等配置数据的持久化管理。它通过JSON文件实现数据的读写和更新，保证多线程环境下的数据安全。是系统数据存储与管理的核心基础模块。

## 技术栈与依赖
- Python 3.x
- 标准库：json、threading、os、uuid
- 无第三方依赖

## 输入与输出
- 输入：
  - 外部传入的视频流URL、围栏坐标点、联系人信息等
  - JSON配置文件：`video_fences.json`、`recipients.json`、`alerts.json`
- 输出：
  - 读取解析后的JSON数据对象（列表/字典）
  - 更新写回JSON文件，保持数据持久化

## 核心功能与逻辑说明
- 初始化时检查相关JSON文件是否存在，不存在则创建空文件
- 读写操作使用线程锁`threading.Lock`，保证多线程访问安全
- 提供视频流、围栏、接收人、告警模板的增删改查（CRUD）接口
- 视频流及围栏通过UUID唯一标识，实现精确定位与修改
- 支持双向绑定视频流与接收人，方便管理报警接收关系
- 读取视频流配置时会重置所有流状态为“stopped”，防止异常状态残留
- JSON读写均做格式化处理，方便手动查看和调试

伪代码示例：
```

初始化StorageManager:
如果文件不存在则创建空列表文件
否则读取文件，并重置视频流状态为 stopped
读取所有数据:
加锁打开文件，读取JSON返回
写入所有数据:
加锁写入格式化JSON
添加视频流:
生成UUID
创建包含基础信息字典，追加到列表
保存列表
更新视频流:
查找对应UUID的流，更新指定字段
保存列表
其他方法类似，确保线程安全和数据一致性

````

## 配置说明
- 文件路径默认：
  - `video_fences.json`：视频流及电子围栏配置
  - `recipients.json`：报警接收人信息
  - `alerts.json`：报警模板配置
- 无额外运行时参数，JSON文件手动维护或通过API接口调用

## 与其他模块的交互
- `app.py`中的HTTP API通过本模块加载和更新配置数据
- `alert_dispatcher.py`读取联系人和模板配置，实现报警推送
- `video_stream.py`读取视频流和围栏信息，执行视频分析
- 前端模块通过HTTP接口间接操作此模块管理的数据，实现界面配置
